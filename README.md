**Was ist WelsGuessr?**
WelsGuessr ist ein Spiel, wo man ein zufälliges Bild innerhalb Wels bekommt, und auf der Karte die Position anzeigen muss. Die „Tägliche Challenge" ist für jeden gleich und nimmt eine zufällige Position täglich um 00:00. Erstelle gerne einen Account!
